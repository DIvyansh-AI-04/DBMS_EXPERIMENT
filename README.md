# 📚 Database Management System (DBMS)

## 📌 About This Repository
This repository contains my DBMS coursework, practical implementations, SQL queries, assignments, and notes. It documents my learning and practical understanding of database management concepts.

## 📖 Topics Covered
- Introduction to DBMS
- Database Architecture
- ER Model and ER Diagrams
- Relational Database Model
- Primary Key, Foreign Key, Candidate Key
- Functional Dependencies
- Normalization (1NF, 2NF, 3NF, BCNF)
- SQL Commands (DDL, DML, DCL, TCL)
- SQL Joins and Subqueries
- Aggregate Functions
- Views
- Stored Procedures
- Triggers
- Transactions and ACID Properties
- Database Constraints

## 🛠️ Technologies Used
- MySQL
- SQL
- Database Management System

To understand database concepts, develop practical SQL skills, and learn how to design, manage, and manipulate relational databases efficiently.
